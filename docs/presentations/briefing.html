From raw bag
to defensible proof

Investigate an incomplete report of vehicle behaviour.

Inspect the recordings, write an EventSpec, and test your reasoning on a different recording.

Check the evidence, explain one failure, and recommend a next action.

A 15–20-minute introduction to the three-hour workshop. This is the accepted participant opening. Use the participant website and canonical quickstart for detail.

Starting requirements

  • Work solo or in pairs.
  • Have civ installed and your supplied kit available.
  • Keep recordings local and make your reasoning traceable.

AI assistance is optional. No paid model, API key or GPU is required.

Setup instructions: kit docs/setup.md

Connected installation uses Git, uv and a supported Python version. These details belong in the setup guide. Participant runtime does not generally require Docker, WSL2 or administrator access.
