# CIV 2026 hackathon handoff site

Private, interactive companion to [`../HACKATHON-HANDOFF.md`](../HACKATHON-HANDOFF.md).

It presents:

- strategic, tactical, and operational planning;
- the expected three-hour attendee journey;
- organizer versus attendee ownership;
- the reference technical pipeline;
- readiness workstreams and unresolved grilling decisions.

## Local preview

```powershell
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Verification

```powershell
npm run build
node --test tests/rendered-html.test.mjs
```

The site is intentionally kept private/local for the current planning phase.
