# EventSpec examples

Copy an example that matches your recording's topics and fields, then adjust its bindings and
conditions. Follow the [quickstart](../docs/quickstart.md) to run and inspect it.

| Dataset | Examples |
| --- | --- |
| Kashiwa | [Right turn](kashiwa/right_turn.yaml) and [deceleration timing](kashiwa/deceleration_timing.yaml). |
| Reims | [Left turn](reims/left_turn.yaml) and [Cave encounter](reims/cave-encounter.yaml) with its [point resource](reims/cave-zones.json). |

The [EventSpec rules](../docs/reference/eventspec-cel-and-derive.md) define expressions and
derivations. The [resource reference](../docs/reference/eventspec-resources.md) defines local
point resources. Examples do not include recordings or scoring labels.
